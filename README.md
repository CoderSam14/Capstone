# Automated Asteroid Detection

An end-to-end pipeline for automated asteroid detection in astronomical FITS image sequences using computer vision, image processing, and deep learning.

## Overview

This repository contains our capstone project on automated asteroid detection from astronomical image sequences. The goal is to develop a reproducible pipeline that can identify moving objects by combining traditional image processing techniques with modern machine learning approaches.

In addition to the implementation, the project includes a literature review, experimental evaluation, and comparisons with existing methods.

## Objectives

* Detect asteroids from astronomical FITS images
* Build an end-to-end detection pipeline
* Evaluate classical and deep learning approaches
* Benchmark different methods
* Document experiments and results
